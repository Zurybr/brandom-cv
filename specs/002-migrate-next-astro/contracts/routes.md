# Route Contracts: Migrate from Next.js to Astro

**Feature**: `002-migrate-next-astro` | **Date**: 2026-06-09

## Route Map

### Static Pages

| Route       | File                          | Method | Description              |
| ----------- | ----------------------------- | ------ | ------------------------ |
| `/`         | `src/pages/index.astro`       | GET    | Homepage / Portfolio     |
| `/blog`     | `src/pages/blog/index.astro`  | GET    | Blog listing             |
| `/404`      | `src/pages/404.astro`         | GET    | Custom not-found page    |

### Dynamic Pages

| Route           | File                            | Method | Params  | Description         |
| --------------- | ------------------------------- | ------ | ------- | ------------------- |
| `/blog/:slug`   | `src/pages/blog/[slug].astro`   | GET    | `slug`  | Individual blog post |

### Static Assets

| Path                  | Source              | Description           |
| --------------------- | ------------------- | --------------------- |
| `/robots.txt`         | `public/robots.txt` | Search engine directives |
| `/sitemap-index.xml`  | Generated by `@astrojs/sitemap` | Auto-generated sitemap |
| `/images/*`           | `public/images/*`   | Static image assets   |

## Page Contracts

### `GET /` — Homepage

**Response**: HTML page with portfolio sections

**Sections rendered** (in order):
1. Hero — profile name, title, summary, avatar, location
2. About Me — summary paragraph
3. Experience — work history timeline
4. Education — academic background cards
5. Skills — categorized skill badges
6. Projects — featured project cards
7. Contact — social links and email

**Data sources**:
- `src/content/profile.json`
- `src/content/experience.json`
- `src/content/education.json`
- `src/content/skills.json`
- `src/content/projects.json`
- `src/content/social-links.json`

**SEO metadata**:
- `<title>`: "Brandom Ledesma — Portfolio"
- `<meta name="description">`: Spanish description
- Open Graph tags: title, description, url, type

---

### `GET /blog` — Blog Listing

**Response**: HTML page listing all blog posts sorted by date (newest first)

**Data source**: `src/content/blog/*.mdx` via `getCollection("blog")`

**Post card displays**:
- Title (linked to `/blog/:slug`)
- Publication date (formatted)
- Category badge (if present)
- Excerpt text
- Reading time

**Empty state**: Message "Aun no hay publicaciones" when no posts exist

**SEO metadata**:
- `<title>`: "Blog — Brandom Ledesma"
- `<meta name="description">`: Spanish description
- Open Graph tags

---

### `GET /blog/:slug` — Blog Post Detail

**Response**: HTML page with full blog post content

**Params**:
- `slug` — URL-friendly post identifier (matches MDX filename without extension)

**Data source**: `src/content/blog/:slug.mdx` via `getEntry("blog", slug)`

**Static paths**: Generated at build time from all MDX files in collection

**Fallback**: 404 page for non-existent slugs

**Post displays**:
- Title
- Formatted date
- Reading time
- Full MDX-rendered content (headings, paragraphs, code blocks, images, links, lists, blockquotes)

**SEO metadata**:
- `<title>`: Post title + " — Brandom Ledesma"
- `<meta name="description">`: Post excerpt
- Open Graph tags: title, description, type (article), published_time

**MDX component styling**:
- h2: Large bold heading
- h3: Medium bold heading
- p: Standard paragraph with spacing
- pre/code: Dark background code block with monospace font
- ul/ol: Styled lists with markers
- blockquote: Left-bordered quote
- a: Primary-colored links with hover underline
- img: Responsive image with rounded corners

---

### `GET /404` — Not Found

**Response**: HTML page shown for any non-matching route

**Displays**:
- "404" heading
- "Pagina no encontrada" message
- Link back to homepage

## Layout Contract

All pages share a common layout (`src/layouts/Layout.astro`):

```
<html lang="es">
  <head>
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1">
    <link rel="sitemap" href="/sitemap-index.xml">
    <!-- page-specific head content via slot/props -->
  </head>
  <body class="[tailwind global styles]">
    <Header />         <!-- sticky nav with mobile menu -->
    <main>
      <slot />         <!-- page content -->
    </main>
    <Footer />         <!-- copyright + social links -->
  </body>
</html>
```

**Navigation links**:
- "Inicio" → `/`
- "Blog" → `/blog`

**Mobile menu**: Hamburger icon toggles nav links on small screens via inline script
